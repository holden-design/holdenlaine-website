┌──────────────────────────────────────────────────────────────────────────────┐
│ STEP 1: CREATE .env FILE WITH STRIPE KEYS                                   │
└──────────────────────────────────────────────────────────────────────────────┘

Create a file named '.env' in the project root directory with:

    STRIPE_PUBLIC_KEY=pk_test_your_key_here
    STRIPE_SECRET_KEY=sk_test_your_key_here

To get these keys:
    1. Go to https://dashboard.stripe.com
    2. Sign in (create account if needed)
    3. Go to Developers → API Keys
    4. Copy test keys (for development)
    5. Paste into .env file
    6. Restart: npm run dev

┌──────────────────────────────────────────────────────────────────────────────┐
│ COMMON ISSUES & SOLUTIONS                                                    │
└──────────────────────────────────────────────────────────────────────────────┘

❌ "Stripe configuration not set"
   → Check if .env file exists in project root
   → Verify STRIPE_SECRET_KEY is set
   → Restart development server: npm run dev

❌ "Gift card code not found"
   → Check code is uppercase: GC-2025-0001-DEMO
   → Verify code exists in redeem-giftcard.json.ts
   → Make sure code hasn't been redeemed already

❌ Emails not being collected
   → Verify data/emails.json file exists
   → Check file permissions are writable
   → Look at browser console for errors

❌ Security headers not appearing
   → Headers apply at API level (response headers)
   → Test with: curl -i http://localhost:3000/api/stripe-checkout.json
   → Look for X-Content-Type-Options, X-Frame-Options, etc.
